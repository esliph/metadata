# Security policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 3.x     | Yes       |
| < 3.0   | No        |

## Reporting a vulnerability

Do not open a public issue for a security problem.

Report it at <https://github.com/Esliph/metadata/security/advisories/new>. This uses GitHub private vulnerability reporting: only you and the maintainer can see the report.

Include:

- The `@esliph/metadata` version.
- The Node.js and TypeScript versions.
- A minimal reproduction.
- The impact.

## What happens next

1. The maintainer confirms the report.
2. The maintainer works on a fix in a private advisory.
3. The maintainer publishes a patch release.
4. The maintainer credits the reporter in the advisory, unless the reporter asks not to be named.

There is no fixed response time.
